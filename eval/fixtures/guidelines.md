# Brand guidelines

## Typography

Use Inter for all text.

- Heading/1 Bold: 32px Bold, line height 40px
- Body: 16px Regular, line height 24px
- Small: 12px Regular, line height 16px

## Colors

Use only these colors, by role.

- background: #ffffff (page background)
- text/primary: #111111 (default text)
- text/secondary: #6b7280 (supporting text)
- surface: #f3f4f6 (cards and panels)
- border: #e5e7eb (dividers and outlines)
- accent/primary: #2563eb (buttons, links and key actions)

## Rules

- Use only the colors and type styles above.
- Do not introduce new colors, fonts or font sizes.
- Name colors by role (for example --color-text-primary), not by hex value.
